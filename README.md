# Superstore Sales Analysis using Microsoft Excel

## Project Overview
This project analyzes Superstore sales data using Microsoft Excel to identify sales trends, profit performance, regional performance, customer segments, and product categories.

## Objectives
- Analyze sales and profit
- Identify top-performing products
- Compare regional performance
- Build an interactive dashboard
- Generate business insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Dashboard Design

  - Quantity

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Orders KPI
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Customer Segment Analysis

## Key Insights
- West region generated the highest sales.
- Technology category produced the highest profit.
- Furniture had lower profit margins.
- Corporate customers generated strong revenue.
- November recorded peak sales.
